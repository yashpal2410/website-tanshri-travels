## 🎯 How to Use

### For Customers

1. **Explore Destinations**
   - Scroll through destination cards
   - Click on any destination to see details
   - Use "Next" button to browse other destinations
   - View attractions, duration, best time to visit, and prices

2. **Book a Tour**
   - Click "Book Now" button in navigation or destination modal
   - Fill in your travel details
   - Select departure city, destination, date, and bus type
   - Add special requests if needed
   - Click "Confirm Booking"
   - Receive booking confirmation

3. **Contact the Company**
   - Scroll to contact section
   - Call the provided phone number
   - Send an email
   - Fill the contact form with your query

### For Website Customization

**To modify company details:**
- Change "Tanshri Travels" to your company name (appears in multiple places)
- Update contact information in the contact section
- Modify email address and phone number

**To add new destinations:**
- Add new destination object in JavaScript `destinations` array
- Include name, emoji, description, attractions, duration, best time, and price
- Update destination grid HTML to include new card

**To change colors:**
- Modify gradient colors in CSS (look for `linear-gradient`)
- Update primary color: `#667eea` and `#764ba2`
- Update accent color: `#ff6b6b`

## 🎫 Booking System Details

### Bus Types & Pricing
- **AC Sleeper**: ₹1,500/seat - Maximum comfort
- **AC Semi-Sleeper**: ₹1,200/seat - Good comfort
- **Non-AC**: ₹800/seat - Budget-friendly

### Booking Process
1. Select departure city
2. Choose destination
3. Pick travel date
4. Enter number of passengers
5. Select bus type
6. Add special requests (if any)
7. Provide contact details
8. Confirm booking
9. Receive confirmation alert

### Form Validation
- All required fields marked with *
- Phone number validation
- Email validation
- Date validation
- Minimum 1 passenger required
- Maximum 50 passengers per booking
